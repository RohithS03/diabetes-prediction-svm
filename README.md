## 📌 Overview

**Diabetes Prediction Engine** is a healthcare machine learning project utilizing Support Vector Machine (SVM) algorithms to analyze medical diagnostic metrics (Glucose levels, BMI, Insulin, Blood Pressure, Age) and accurately predict diabetes onset risk.

---

## ✨ Features & Methodology

- 🧪 **Data Preprocessing & Standardized Scaling:** Handles missing values and normalizes feature distributions.
- 🎯 **Support Vector Classifier (SVC):** Hyper-parameter tuned linear and RBF kernel SVM models.
- 📊 **Performance Evaluation:** Confusion matrix analysis, ROC-AUC curves, and classification reports.
